# 张怀民 Foru

你想说时，我在。你没说完，我等。

[在线 Demo](https://foru-opal.vercel.app)

Foru 是综合 AI 助手的连续语音伙伴原型。一次开启，在健身房、驾驶、安静咖啡馆与回家之间接续同一个约见任务。

## 立即运行

下载或克隆后，直接双击 `index.html`。无需安装、联网、账号、麦克风或 API 密钥。

也可以执行 `python3 -m http.server 8080` 后访问 http://localhost:8080 。

点击“自动演示完整流程”观看18步主线；或点击“下一步”，随时尝试插话、噪声、取消消息、耳机断开与模拟断网。自动演示是约一分钟的脚本流程，并非真实语音识别。

## 已实现

WHO / WHEN / HOW / SURE 统一规则；有边界的伴随期；噪声保持现态；语义停顿等待；字幕输出中断和账本分界；正门改北门的任务更新；消息草稿确认、取消和防重复执行；车机接力模拟；高负荷延后；耳机断开静音；用户确认后保存偏好，支持编辑、删除、刷新保留及JSON导出。

## 技术结构

- `engine.js`：纯状态机，18步剧本。
- `app.js`：DOM、可选浏览器TTS、字幕、计时、localStorage、导出。
- `index.html`：响应式界面，无外部前端依赖。
- `test-engine.js`：可选执行 `node test-engine.js`，12项关键不变量检查。
- `vercel.json`：静态部署配置。

## 必须明确的边界

这是确定性模拟，不包含真实ASR、声纹、全双工音频模型、地图、通讯和跨设备账户同步。所有联系人、行程、发送和导航结果都是演示数据。TTS取决于浏览器和系统语言包；默认关闭，文字模式不会发声。账本记录90毫秒/字的字幕进度，不代表真实音频播放位置。10秒休息计时仅用于演示，不是训练处方。记忆只在当前浏览器保存；file协议或隐私模式可能限制存储，页面提供降级提示。

本地状态测试不能证明真实识别率、声学停止延迟或用户体验收益。评测文档中的门槛均为待验证目标。

## 设计来源

融合用户提供的Aura、知音Echo、回声EchoVoice(ds)方案与此前Flow策略引擎。保留原仓库的深蓝、蓝绿视觉系统，升级其可操作逻辑。AI辅助完成方案整合、代码与文档编写。
